# BoxForge 2026-10-15

首次日期版本的发布候选说明；实际发布状态以 GitHub Release 为准。
本次确立产品契约与 Linux x64 CLI 交付，不修改引擎、命令或默认生成策略。

## Input

基线：读取 YAML `proxies`，支持 Trojan、VLESS、Hysteria2、Shadowsocks 和
AnyTLS 的已声明子集；严格拒绝无法安全映射的节点，整次引擎请求失败。
不承诺完整 Clash 配置等价转换，不转换来源 `rules`、`proxy-groups`。
字段、transport 与拒绝项见包内 `docs/generated-config.md`。

## Target

基线：sing-box 1.15；最低 alpha.1，资格验证锁定官方 `1.15.0-alpha.8` /
`b609f959f57ce34416c51c7b87ce4a76f2e1df56`。这不是其他版本或定制核心的
兼容性保证。来源研究与验证范围见包内 `docs/protocol-validation.md`。

## CLI

既有 `generate`、参数、退出码和事务输出目录语义无变化。
新增 Linux x64 自包含归档，无需安装 .NET SDK；启动文件名为 `boxforge`。
附 SHA256SUMS 与 RELEASE.json，后者记录源码完整 SHA、日期 tag、SDK 和 RID。
Core/CLI/Server 项目结构、Web/API 契约均无变化，归档仅分发 CLI。

## Behavior

默认策略无变化：IPv4-only、DNS/route 优先级、地区 selector/URLTest、
平台 TUN/bridge、Tailscale、transport tuning 保持当前基线。
支持的显式节点语义优先于缺失值调优；详细规则见包内 docs。
本次交付变更不预期改变相同输入、平台与宿主配置下的生成 JSON。

## 验证与升级

发布流程运行全套 .NET 测试，并解包 CLI、生成所有 fixture 的三平台配置，
逐文件对比源码运行的结果；任一步失败不发布。
官方核心、协议回环和未验证路径的资格记录见包内协议验证文档；发布流程
本身不证明真实 TUN、设备 IPv6、生产订阅、远端节点或 live tailnet 行为。

从 main 消费切换到本版本时，固定 tag 与完整 SHA，并保留输入、平台及宿主
配置条件。先在临时目录比较产物并运行官方核心检查，再替换正式输出。
